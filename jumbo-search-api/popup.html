Jumbo Search API

MCP Tools
This extension registers two MCP tools that use the Webfuse Automation API: domSnapshot() for reading the page and navigate() for searching.
jumbo_search
Searches a product on Jumbo, waits for results, scrolls, and returns products via DOM snapshot.
jumbo_scan_page
Scans the current Jumbo page for products using Automation API DOM snapshot.
